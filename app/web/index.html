从数据集到开发板

  1. 准备数据集（PC）按 YOLO 格式放 dataset/images 与 dataset/labels，运行 prepare_dataset.py 校验并生成 configs/dataset.yaml。数据集不拷入板子。
  2. 训练（PC/GPU）执行 python training/train.py，训练 YOLOv8n；验证指标写入 runs/fire/.../metrics.json。
  3. 导出 ONNX（PC）python training/export_onnx.py --weights runs/fire/yolov8n_fire/weights/best.pt，输出到 models/fire_yolov8n.onnx。
  4. 转 OM（板端）bash deployment/convert_om.sh 调用 ATC，目标芯片 Ascend310B4，生成 models/fire_yolov8n.om。
  5. 启动服务bash deployment/start.sh，浏览器打开 http://<板端IP>:8000/，使用 USB 摄像头实时检测。
板端只带模型，不带数据集 打包脚本会排除 dataset/、runs/、training/；Atlas 4GB 内存建议使用 YOLOv8n + 640 输入。
